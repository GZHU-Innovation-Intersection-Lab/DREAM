# Data availability statement

This repository is the peer-review-stage public data release for the manuscript:

**DREAM: Deployment-Time Priority Stratification, Review Routing, and Threshold Adaptation for Generative AI Incidents**

## Publicly available in the current release

The current public release contains only the initial incident-level labeling dataset used as the manuscript input layer:

- `dream_initial_labels_1134.csv`
- 1,134 incident records
- six-dimensional scores: `Da`, `A`, `R`, `E`, `Di`, and `M`
- supporting documentation in `DATASET_SCHEMA.md`, `RELEASE_NOTE.md`, and `CITATION.cff`

## Not yet included

The following materials are not part of the current public release:

- downstream validation outputs
- expert-panel materials
- proxy-evidence artifacts
- manuscript-generation or analysis code

## Planned post-acceptance expansion

After article acceptance, the repository will be expanded to include the remaining data products and code to the extent permitted by project governance, documentation readiness, and any applicable disclosure constraints.
